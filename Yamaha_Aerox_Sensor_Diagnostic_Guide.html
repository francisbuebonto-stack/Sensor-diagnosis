🔄 October 2026 Update #3 LATEST

Updated by: Document Drafter Agent | Reference: Yamaha Aerox GDR155 Service Manual — 36-tooth reluctor ring specification

Sensor Old Value New Value Reason
CKP Sensor — Unit & Range unit: "pulse", min: 1, max: 1
(binary pass/fail — slider non-functional)		 unit: "pulses/rev", min: 34, max: 36
(36-tooth reluctor ring, 34–36 acceptable)		 Original binary (0/1) definition caused a zero-width slider range in the Scenario Simulator, making it non-functional. Replaced with pulse count per revolution based on the Aerox 155 FI 36-tooth reluctor ring. Low reading (<34) = missing/chipped teeth; High (>36) = electrical noise causing false pulses. Symptoms, causes, and diagnosis rules updated accordingly.

🔄 October 2026 Update #2

Updated by: Document Drafter Agent | Reference: Yamaha Aerox GDR155 Service Manual — ECU Fault Code Table

Sensor Change Fault Code Reason
CKP Sensor (Crankshaft Position) New — Added Code 12 CKP is confirmed on Aerox 155 FI ECU (Code 12). Monitors pulse count from crankshaft reluctor ring. Essential for ignition timing and fuel injection sync.
ISC / Idle Speed Control New — Added Code 61 ISC (stepper motor) is confirmed on Aerox 155 FI ECU (Code 61). Controls air bypass at idle to maintain stable RPM. Failure causes erratic or uncontrolled idle.

🔄 October 2026 Update #1

Updated by: Research Assistant | Reference: Yamaha Aerox GDR155 Service Manual + Multi-source cross-verification

Sensor Old Value New Value Reason
Engine RPM (Idle) 550–850 RPM 1,000–1,500 RPM 550–850 RPM is too low for a fuel-injected 155cc engine. Factory-standard warm idle for FI 155cc scooters is 1,000–1,500 RPM. Previous value was derived from carbureted/smaller engine references.
MAP (Manifold Absolute Pressure) 20–48 kPa 20–80 kPa Old max of 48 kPa only covered idle-to-light-load. At wide-open throttle (WOT) the MAP can rise to ~80 kPa on a naturally aspirated FI engine. Extended range avoids false "High" flags during hard acceleration.
Mass Air Flow (MAF) 2–6 g/s 1.5–6 g/s At very light throttle or a freshly started warm idle, MAF can read as low as 1.5 g/s without indicating a fault. Previous minimum of 2 g/s caused false "Low" warnings at legal idle conditions.
Intake Air Temperature (IAT) 20–40°C 20–45°C Yamaha Aerox is primarily marketed and used in tropical countries (Philippines, Indonesia, Thailand) where ambient temperatures regularly exceed 40°C. Ceiling raised to 45°C to avoid false positives in normal tropical operating conditions.
Battery Voltage — Testing Steps No factory spec referenced Added: Factory battery is 12V, 6.0 Ah Factory battery specification (12V, 6.0 Ah) added to the testing procedure steps for reference when replacing or bench-testing the battery. Confirmed from Yamaha Aerox GDR155 specification sheet.
ECT, O2, TPS, Fuel Pressure, O2 Response Unchanged Unchanged Values cross-verified against multiple sources and confirmed correct. No changes required.
